# safdar-s-ai-cockpit

Personal portfolio + AI cockpit website for Safdar Nizam Mohammed.

Built with React, TypeScript, Vite, TailwindCSS.

## Local development

Install and run:

```powershell
npm ci
npm run dev
```

## Deploy

This repository is configured to deploy to GitHub Pages. Production build uses the `base` set in `vite.config.ts`.
